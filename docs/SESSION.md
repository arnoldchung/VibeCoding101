# 2시간 수업 안내

코딩 경험이 없는 성인 연구자를 위한 수업입니다. 네 학습 목표는 바이브 코딩 이해, 프롬프트 작성, Skills 활용, 나만의 Skill 제작입니다. GitHub와 지뢰찾기는 마지막 적용 실습입니다.

## 사전 준비

GitHub·AI 코딩 도구 로그인, 강사 저장소 Fork와 본인 Fork Clone을 수업 전에 마칩니다. 설치가 막히면 짝 활동으로 참여합니다. 화면 공유는 [세션 슬라이드](https://arnoldchung.github.io/VibeCoding101/session.html)를 사용합니다.

## 첫 60분

| 시간 | 활동 |
| --- | --- |
| 0–10분 | 바이브 코딩의 개념·사람의 역할·Plan/Edit/Auto |
| 10–22분 | 목적·맥락·요구사항·제약·성공 조건을 담은 프롬프트 작성 |
| 22–32분 | Skills·마켓 이해, 추천 Skill과 강사 적용 시연 |
| 32–45분 | idea-to-spec SKILL.md 작성·호출·두 입력 테스트·한 줄 개선 |
| 45–60분 | GitHub 변경 기록, 지뢰찾기 한 미션의 계획·구현·검증·커밋 |

설문은 각 구간 시간 안에 포함합니다. [Skill 제작 안내와 기록지](../exercises/skills/README.md), [예제 파일](../exercises/skills/idea-to-spec/SKILL.md)을 사용합니다. 예제는 자동 설치되지 않으므로 선택한 도구의 프로젝트 경로로 복사합니다.

Skill 실습 완료 기준은 파일 1개, 호출 결과 2건, 지침 수정 1건, 재검사 기록입니다. 일반 프롬프트에 본문을 붙여 넣었다면 Skill 설치·호출 성공과 구별해 기록합니다.

[지뢰찾기](../exercises/minesweeper/README.md)는 placeMines 한 함수에 집중합니다. 모든 미션 완성은 첫 시간 필수 조건이 아닙니다. 브랜치·PR·복구의 상세 연습은 [GitHub 안내](GITHUB.md)를 참고하는 후속 활동입니다.

## 다음 60분

| 시간 | 활동 |
| --- | --- |
| 0–10분 | 내 Skill로 앱 명세와 성공 조건 확정 |
| 10–30분 | 작은 첫 버전 생성·실행·기준 커밋 |
| 30–45분 | 짝 테스트와 오류 재현·수정 |
| 45–55분 | 개선 한 가지, 필요한 Skill 지침 조정, 재검사 |
| 55–60분 | 앱 동작·Skill 적용 효과·남은 한계 시연 |

자신의 업무·관심사에 맞는 앱을 만들거나 지뢰찾기를 확장합니다. 새 프로젝트는 `projects/내-프로젝트/`처럼 실습 폴더와 구분해 둡니다.

## 발표할 내용

- 누구의 어떤 작업을 돕는가?
- 어떤 요청문과 Skill을 사용했는가?
- 어떤 입력과 예상 결과로 확인했는가?
- Skill 지침을 어떻게 바꾸고 결과가 어떻게 달라졌는가?
- 아직 확인하지 못한 것은 무엇인가?
