# 바이브 코딩 101

**설치부터 함께 배우는 2시간 30분 세미나입니다. 코딩 경험이 없어도 참여할 수 있습니다.**

## 준비물

- **개인 노트북·충전기**, 인터넷에 연결할 수 있는 환경
- **AI 계정 하나:** OpenAI / Claude / Google 중 사용할 서비스의 계정을 준비하고 로그인 확인
- **AI 앱 사전 설치:** 개인 노트북에 [ChatGPT 앱](https://chatgpt.com/download/) / [Claude 앱](https://claude.com/download) / [Google Antigravity 앱](https://antigravity.google/download) 중 사용할 앱 하나를 설치하고 로그인
- **프로그램 설치:** 개인 노트북에 프로그램을 설치할 수 있도록 준비
- **GitHub 계정은 선택:** 마지막 저장·공유 실습에 사용할 수 있습니다.
- **만들고 싶은 작은 앱 아이디어 하나**

**앱 하나를 미리 설치·로그인하고, 실습 폴더 열기부터 수업에서 함께 진행합니다.** CLI·터미널·VS Code·Node.js는 필수 준비물이 아닙니다.

[앱별 준비 안내](docs/APP-SETUP.md)에서 일반 채팅이 아닌 로컬 프로젝트 작업 화면을 확인해 주세요.
