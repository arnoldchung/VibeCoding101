# 바이브 코딩 101

**설치부터 함께 배우는 2시간 30분 세미나입니다. 코딩 경험이 없어도 참여할 수 있습니다.**

## 준비물

- **노트북·충전기**, 인터넷에 연결할 수 있는 환경
- **AI 계정 하나:** Codex / Claude Code / Gemini CLI 중 사용할 도구의 계정과 로그인 확인
- **프로그램 설치 권한:** 회사·학교 노트북은 설치 가능 여부를 미리 확인
- **GitHub 계정은 선택:** 마지막 저장·공유 실습에 사용할 수 있습니다.
- **만들고 싶은 작은 앱 아이디어 하나**

**VS Code·Node.js·선택한 CLI의 설치와 실습 폴더 준비는 수업에서 함께 진행합니다.** 세 AI 도구를 모두 설치하거나 구독할 필요는 없습니다.
