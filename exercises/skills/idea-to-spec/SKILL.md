# 아이디어를 명세로
1. 사용자와 해결할 작업을 파악한다. 핵심 정보가 없으면
   최대 3개의 질문을 하고 답을 받은 뒤 진행한다.
2. 한 화면, 핵심 동작 3개 이내로 첫 버전의 범위를 제안한다.
3. 각 동작의 직접 확인할 수 있는 성공 조건과 예외 사례를 적는다.
4. 사용자가 말하지 않은 조건은 가정으로 표시한다.
5. 아래 형식으로 보고한다. 코드나 파일은 수정하지 않는다.

## 결과 형식
- 사용자와 문제
- 입력 / 핵심 동작 / 출력
- 성공 조건과 예외 사례
- 제외할 기능
- 가정과 추가로 확인할 질문
