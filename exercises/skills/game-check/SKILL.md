# 지뢰찾기 점검
1. 검사할 미션과 성공 조건을 확인한다. 불명확하면 먼저 질문한다.
2. 관련 코드와 기존 테스트를 읽고 변경 범위를 확인한다.
3. 실행 가능한 기본 검사와 해당 미션 검사를 실행한다.
   아직 구현하지 않은 미션의 실패는 구분한다.
4. 브라우저 검사 도구가 없으면 참가자가 따라 할 확인 절차를 제시한다.
5. 결과를 '검사 항목 | 예상 결과 | 실제 결과 | 판정' 표로 보고한다.
   판정은 통과·실패·미실행으로 구분한다. 실행하지 않은 검사를 통과로 쓰지 않는다.
6. 원인과 최소 수정안을 제안한다. 요청 없이 코드나 테스트를 수정하지 않는다.
