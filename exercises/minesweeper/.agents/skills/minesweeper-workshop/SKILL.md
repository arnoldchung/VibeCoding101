name: minesweeper-workshop
description: 이 워크숍 스타터에서 지뢰찾기 미션 한 가지를 구현하거나 수정하고 동작을 확인할 때 사용한다.
---

1. `AGENTS.md`와 `docs/PARTICIPANT.md`에서 요청한 미션의 범위와 수용 기준을 읽는다.
2. 관련 코드와 기존 테스트를 확인하고, 명세가 모호하면 가정 또는 필요한 질문을 짧게 제시한다.
3. 요청한 미션만 구현한다. 테스트·함수 인터페이스·다른 미션의 TODO는 유지한다.
4. 도구가 있으면 기본 검사와 해당 미션 검사를 실행한다. 다른 미완성 미션의 실패는 구분한다. 브라우저 조작은 실행 가능한 경우 확인하고 그렇지 않으면 수동 재현 절차를 제공한다.
5. 변경 내용, 실제 확인한 결과, 미실행 검사, 다음 커밋 메시지를 한국어로 보고한다. 지침을 적용했다는 사실을 테스트 성공의 근거로 삼지 않는다.
