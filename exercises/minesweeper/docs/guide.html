참가자 빠른 시작

한 함수씩, 나의 게임으로

지뢰찾기 화면은 준비되어 있습니다. 네 가지 게임 규칙을 AI와 구현하고, 직접 확인한 결과를 커밋으로 남겨 보세요.

현재는 미완성 스타터입니다. 지뢰가 없고 클릭한 한 칸만 열립니다. 과제 구현 전의 예상 동작입니다.

먼저 나의 복사본 만들기

  1. 강사 GitHub에서 Fork를 누르고 본인을 Owner로 선택합니다.
  2. 본인 Fork를 GitHub Desktop으로 Clone합니다.
  3. Clone한 폴더의 index.html을 브라우저로 엽니다.
  4. 같은 폴더를 AI 코딩 도구로 열고 새 브랜치 feature/minesweeper를 만듭니다.

첫 요청문

AGENTS.md와 src/engine.js를 먼저 읽어 주세요.
미션 1의 placeMines만 구현해 주세요.
서로 다른 칸에 정확히 mineCount개의 지뢰를 놓고 첫 클릭은 보호해 주세요.
rng를 사용해 유한한 반복으로 끝나도록 해 주세요.
다른 미션은 미리 구현하지 말고, 변경 이유와 확인할 검사를 설명해 주세요.

네 가지 미션

  1. 지뢰 배치: 정확히 10개, 중복 금지, 첫 클릭 보호.
  2. 숫자 계산: 자기 자신을 제외한 주변 8방향. 모서리와 행 경계 확인.
  3. 빈 영역: 연결된 0과 경계 숫자 열기. 지뢰·깃발은 열지 않기.
  4. 승리 판정: 모든 안전한 칸이 열려야 성공. 깃발 개수와 구별.

매번 이 순서로

성공 조건 작성 → 한 가지 구현 → 예상값과 실제 결과 비교 → Diff 확인 → 커밋 → 본인 Fork로 Push.

Node.js가 이미 있다면 npm test로 기본 검사를 실행합니다. npm run test:missions는 처음에는 실패하는 과제 검사입니다. 설치 없이도 직접 플레이하며 수동 확인표를 사용할 수 있습니다.
