# 지뢰찾기 집중 실습 확장안

이 문서는 지뢰찾기를 두 시간 동안 확장할 때의 선택 진행안입니다. 기본 수업은 [전체 수업 안내](../../../docs/SESSION.md)를 따릅니다.

## 수업 목표

코딩 경험이 없는 연구자가 명세·검증·변경 기록을 연결해 작은 프로그램을 완성하는 경험을 합니다. 정답 코드를 복사하는 대신 한 미션씩 요청하고 실제 결과를 확인하게 합니다.

기존 연구 메모 앱 실습을 지뢰찾기 실습으로 대체하는 진행안입니다. 기존 슬라이드의 일반 개념·GitHub·Skills 부분은 재사용할 수 있지만, 앱 예제·데이터 구조·CSV 테스트는 아래 활동으로 바꿔 진행하세요. 슬라이드 파일 자체를 이 저장소에 섞어 넣지 않았습니다.

## 수업 전 15–20분 권장

- GitHub 계정·Desktop 로그인을 완료하도록 안내합니다.
- 참가자가 자신의 Fork를 Clone했는지 확인합니다. 원본을 Clone해서 강사에게 쓰기 권한을 요청하게 하지 않습니다.
- AI 코딩 도구에서 같은 폴더를 열고 `index.html` 실행을 확인합니다.
- 강사는 로컬 사본에서 미션 1~2를 미리 구현하고 시연합니다. 기본 브랜치는 미완성 상태를 유지합니다.
- Node.js는 자동 검사를 원하는 참가자에게만 필요합니다. 수동 확인표로도 참여할 수 있습니다.
- 인터넷이나 인증 문제가 있으면 배포 ZIP으로 로컬 제작을 시작하고 Fork·Push는 이후에 이어갑니다.

## 첫 60분 함께 만들기

| 시간 | 활동 | 확인 결과 |
| --- | --- | --- |
| 0–8분 | 바이브 코딩, 연구자의 설계·검증 역할 | 한 행동의 성공 조건을 말함 |
| 8–16분 | Fork와 Clone, 폴더와 코드 구조 | 본인 Fork와 실행 화면 확인 |
| 16–24분 | README 변경, Diff, 커밋, Push, Revert 시연 | 저장·커밋·Push 차이를 설명 |
| 24–30분 | 프로젝트 Skill 읽기, 4개 TODO와 수용 기준 | 이번 구현 범위를 지정 |
| 30–43분 | 미션 1 지뢰 배치를 AI와 구현 | 정확한 개수와 첫 클릭 안전 확인 |
| 43–55분 | 미션 2 숫자 계산, 모서리 테스트 | 고정 배치에서 예상 숫자 비교 |
| 55–60분 | 커밋·Push, 다음 목표 선택 | 미완성·검증 완료를 구분 |

## 다음 60분 직접 확장

| 경과 시간 | 활동 |
| --- | --- |
| 0–10분 | 워크시트로 미션 3의 명세·예상값 정리 |
| 10–25분 | 빈 영역 열기 구현과 검사 |
| 25–35분 | 승리 판정 구현, 패배·종료 후 입력 검사 |
| 35–45분 | 짝과 수동 테스트, 재현 절차로 수정 |
| 45–55분 | 개성 있는 개선 한 가지, 회귀 확인, 커밋·Push |
| 55–60분 | 1분 시연: 동작·테스트·한계·커밋 |

미션 3의 탐색이 어려우면 강사와 함께 진행하거나 미션 1~2의 검증과 디자인 변경으로 범위를 줄입니다. 모두에게 4미션 완성을 보장하는 시간표는 아닙니다. 브랜치·PR 전체 연습은 진도가 빠르거나 수업 후에 수행합니다.

## 관찰할 포인트

1. AI에게 게임 전체를 한 번에 요청하는가, 한 미션을 특정하는가?
2. 지뢰 개수와 첫 클릭 안전을 구분해 확인하는가?
3. 코드를 읽었다는 사실과 실제 실행 결과를 구분하는가?
4. 변경 후 기존 깃발·리셋·패배 동작을 다시 검사하는가?
5. 실패한 테스트를 지우거나 기대값을 바꾸지 않는가?

## 자동 검사 해석

`npm test`는 기본 뼈대 검사입니다. `npm run test:missions`는 처음에는 실패하는 수용 기준입니다. 전체 과제 검사가 통과해야 완성된 게임의 논리를 확인했다고 말할 수 있습니다. 테스트는 모든 UI나 모든 가능한 보드를 다루지 않으므로 실제 플레이를 함께 확인합니다.

## Skills 시연

`.agents/skills/minesweeper-workshop/SKILL.md` 또는 `.claude/skills/minesweeper-workshop/SKILL.md`를 열어 범위·검사·보고 절차를 읽습니다. 사전 확인한 도구에서 한 미션만 호출하세요. 미지원 환경에서는 본문을 프롬프트로 제공합니다.

## 완료 기준

핵심: 본인 Fork, 실행 화면, 미션 한 가지 이상, 검증 기록, 본인 원격 커밋. 도전: 4미션 완성, 전체 과제 검사, 자신만의 기능, 본인 Fork 안의 PR.
