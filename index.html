수업 자료

GitHub와 버전 관리

파일을 저장하는 것, 변경을 커밋하는 것, GitHub로 보내는 것을 구별합니다.

Fork / Clone
GitHub에 내 복사본을 만들고, 내 컴퓨터로 가져옵니다.
Diff / Commit
무엇이 달라졌는지 확인하고 변경 이유와 함께 기록합니다.
Push / Pull
내 커밋을 원격에 보내고 원격의 변경을 가져옵니다.
Branch / PR
별도 경로에서 실험하고 변경 내용과 테스트를 검토합니다.

수업 전 준비

  1. GitHub 계정과 GitHub Desktop 로그인을 확인합니다.
  2. 강사 저장소를 Fork하고 본인 Fork를 Clone합니다.
  3. README 한 줄을 바꿔 Diff·커밋·Push를 확인합니다.

약 15–20분의 사전 준비를 권장합니다. 설치가 어려우면 웹 편집과 ZIP 다운로드로 참여할 수 있습니다.
