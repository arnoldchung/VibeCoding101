교안 11

버전 관리는 변경의 연구 기록입니다

Git: 내 컴퓨터의 변경 이력

  • 저장소: 파일과 이력을 묶은 프로젝트
  • 커밋: 선택한 변경을 기록한 시점
  • Diff: 이전과 달라진 내용 비교
  • 커밋 ID: 특정 기록을 식별하는 값

GitHub: 이력을 원격에서 공유

  • 원격 저장소에 커밋 업로드
  • 다른 컴퓨터와 변경 동기화
  • 브랜치와 PR로 검토·협업
  • 코드를 올려도 앱이 자동 배포되지는 않음

AI가 수정하기 전의 작동 버전과 수정 이유를 남깁니다.

강사용 진행 노트

연구 초안의 최종·진짜최종 파일 대신 한 프로젝트의 변경 이력을 남긴다고 비유한다. Git은 버전 관리 도구, GitHub는 Git 저장소를 호스팅하고 협업하는 서비스다. 커밋이 과학적 재현성 자체를 보증하지는 않는다. 실행 환경·자료·검증 기록도 필요하다. 오늘은 개인 Private 실습 저장소에서 작은 변경을 기록한다.

강사용 진행 노트

파일 저장과 커밋을 구분하게 한다. Clone은 원격 저장소와 이력을 처음 내 컴퓨터로 가져오는 작업이다. Fetch는 원격의 새 소식을 확인하고 Pull은 내 브랜치에 가져와 반영한다. Push 실패 시 반복 클릭 대신 원격 변경이나 권한을 확인한다. 브라우저에서 편집·커밋하면 GitHub 쪽에 바로 기록되므로 별도 로컬 Push 단계가 없다.

교안 14

실습: README 한 줄을 두 번 기록

  • README에 “상태: 기획 완료”를 적고 저장합니다
  • Changes에서 Diff 확인, 커밋 후 Push합니다
  • “상태: 첫 실습 진행”으로 바꾸고 다시 기록합니다
  • GitHub에서 두 커밋과 변경 내용을 확인합니다

메시지 예: “수업 목표 기록” / “실습 진행 상태 갱신”

강사용 진행 노트

강사는 미리 준비한 README 파일을 일반 텍스트 편집기 또는 AI 도구로 수정한다. Desktop Current Repository와 Current Branch를 확인한다. Changes에서 README만 선택하고 Summary에 변경 이유를 쓴 뒤 Commit to main, Push origin을 누른다. 두 번째도 같은 순서다. 초기 README 커밋은 이미 있으므로 “총 커밋이 두 개”라고 말하지 않고 “새 커밋 두 개 추가”라고 표현한다. 브라우저 참가자는 README 편집 아이콘과 Commit changes로 같은 두 변경을 기록한다. 수업용 개인 저장소의 main에서 수행하는 기초 연습이며 협업 변경은 브랜치를 권장한다.

교안 15

되돌리기도 새로운 기록으로 남기기

  • 커밋하지 않은 변경이 없는지 확인합니다
  • History에서 방금 만든 두 번째 커밋을 고릅니다
  • Revert Changes in Commit 후 결과를 확인합니다
  • Push하고 README와 원격 이력을 확인합니다

원래 커밋은 남고, 그 변경을 취소하는 새 커밋이 생깁니다.

강사용 진행 노트

독립된 README 최신 커밋 하나를 되돌리는 간단한 사례만 시연한다. 이전 상태 문장으로 복구됐는지 파일을 열어 확인한다. Revert는 과거 전체 상태로 무조건 점프하는 기능이 아니라 선택 커밋의 변경을 반대로 적용하는 작업이다. 후속 변경이 있으면 충돌할 수 있다. 충돌이 뜨면 중단하고 강사 도움을 받는다. Reset·force push는 가르치지 않는다. 브라우저 대안은 직전 문장을 다시 편집해 새 커밋으로 저장한다. 이 대안은 Desktop의 Revert 명령을 실행한 것과 구별한다.

두 번째 시간의 진행과 점검 지점

  • 0–10분 사용자·문제·성공 조건 정리

30분에 핵심 동작이 없으면 기능 범위를 줄이고, 45분부터 안정화에 집중합니다.

강사용: 설문 자리 교체 방법
  1. HTML에서 id="menti-1", menti-2, menti-3을 검색합니다.
  2. 각 menti-insertion-point에 공유 링크 또는 공식 임베드 코드를 넣습니다.
  3. QR 이미지와 참여 코드를 추가하고, 회색 안내 문구와 빈 자리 표시를 교체합니다.
  4. 수업 전 학생 화면에서 접근 가능 여부를 확인합니다.

현재는 자리 표시만 있으며 실제 설문 연결이나 응답 수집은 없습니다.
