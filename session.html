10–35분 · 설치 따라 하기

1 · VS Code 설치하고 실행하기

  1. VS Code 다운로드에서 자신의 운영체제를 선택합니다.
  2. Mac: 압축을 풀고 Applications로 이동합니다. Windows: 설치 파일을 실행합니다.
  3. VS Code를 실행합니다. 아직 프로젝트가 없어도 괜찮습니다.

완료 확인: VS Code 창이 열렸나요? 파일을 편집하는 곳과 AI에게 요청하는 곳을 곧 구분해 봅니다.

10–35분 · 작업 폴더

2 · 지뢰찾기 스타터 내려받기

  1. 수업 저장소를 엽니다.
  2. Code → Download ZIP을 누릅니다. GitHub 로그인 없이 받을 수 있습니다.
  3. ZIP을 풀고 Documents 같은 찾기 쉬운 폴더로 옮깁니다.
  4. VS Code의 File → Open Folder에서 exercises/minesweeper를 엽니다.

폴더 안에 index.html, src, tests, AGENTS.md가 보이면 맞는 위치입니다. Clone 경험이 있다면 본인 Fork의 같은 폴더를 열어도 됩니다.

3 · 터미널과 작업 폴더 이해하기

터미널

완료 확인: 현재 경로 끝이 minesweeper이고 index.html이 보이나요? 명령 앞의 $나 PS는 입력하지 않습니다.

10–35분 · 실행 도구

4 · Node.js 설치하고 버전 확인하기

  1. Node.js 다운로드에서 LTS와 운영체제에 맞는 설치 파일을 선택합니다.
  2. 안내에 따라 설치한 뒤 VS Code를 다시 열고 새 터미널을 엽니다.
  3. 아래 명령을 한 줄씩 입력합니다.
node --version
npm --version

완료 확인: 두 명령에 버전 번호가 나오면 됩니다. Node.js는 CLI와 테스트 실행에 사용하며, 게임 화면 자체는 브라우저에서 열 수 있습니다.

35–50분 · 작업 모드

Plan · Edit · Auto: 작업 방식과 권한

Plan-mode

문제를 이해하고 변경 계획을 세웁니다.

수정할 파일과 성공 조건, 확인 방법을 먼저 정합니다.

Edit-mode

정해 둔 범위에서 파일을 수정합니다.

변경 후 Diff와 동작을 확인합니다.

Auto-mode

설정된 권한 안에서 작업을 자동으로 이어 갑니다.

자동으로 진행해도 결과는 확인해야 합니다.

이 세 이름은 모든 도구의 공통 메뉴가 아닙니다. 선택한 도구의 실제 모드와 권한을 확인하세요.

110–120분 · GitHub 시연

GitHub · 내 복사본에 기록 남기기

  1. GitHub 계정으로 로그인하고 강사 저장소를 본인 계정으로 Fork합니다.
  2. GitHub Desktop 사용자는 본인 Fork를 Clone합니다.
  3. ZIP에서 작업했다면 수정한 engine.js와 만든 Skill 폴더를 같은 상대 경로로 복사합니다.
  4. Desktop에서 Diff 확인 → Commit → Push합니다.

Clone 폴더와 ZIP 작업 폴더는 다릅니다. 실행했던 수정본이 내 Fork에 들어갔는지 확인하세요. 강사는 시연하고, 계정·설치가 안 된 참가자는 로컬 저장 후 수업 뒤 진행해도 됩니다.
